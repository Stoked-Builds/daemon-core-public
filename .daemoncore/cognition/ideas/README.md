# Ideas

Pre-backlog exploration space.

Use this directory for:
- Early-stage feature ideas
- Research notes
- Proposals that haven't been committed to the backlog

## Structure
- `epics/` — Large initiative ideas
- `features/` — Feature-level ideas
- `tasks/` — Task ideas
- `user-stories/` — User story drafts
- `_templates/` — JSON templates for work items
